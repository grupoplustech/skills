# 👥 Collaborators & Community Governance

Welcome to the **Grupo Plus Tech Skills** project. This document outlines how maintainers, core collaborators, and community contributors work together.

---

## 🏛️ Project Governance

This repository is maintained by **Grupo Plus Tech** as an open-source initiative under the MIT License. Our mission is to provide rigorous, production-grade agent skills across multiple AI architectures (Hermes, Claude, Cursor, Gemini, GPT), with a special focus on Systems DevOps, Automation, and Amateur Radio (Ham Radio) protocols.

### Roles & Responsibilities

* **Core Maintainers (@grupoplustech):**
  * Architecture oversight, repository permissions, release tagging.
  * Security reviews (ensuring zero leaked credentials or private infrastructure references).
  * Final sign-off on new skill categories and breaking changes.
* **Domain Collaborators (Subject Matter Experts):**
  * **Amateur Radio (Ham Radio):** Operators with licensed callsigns reviewing DMR codeplug architectures, CAT protocols, bandplans, and hardware interfaces.
  * **Agent Ops & DevOps:** Engineers reviewing agent lifecycles, backup strategies, and multi-agent patterns.
  * **Integrations:** Developers verifying API protocols, SDK edge cases, and automation scripts.
* **Community Contributors:**
  * Anyone submitting bug reports, documentation clarifications, hardware test reports, or PRs.

---

## 🎖️ Becoming a Collaborator

We actively invite experienced radio amateurs, systems engineers, and prompt architects to become designated collaborators!

To become a recognized collaborator:
1. Submit **3 or more high-quality PRs** (new skills, tested edge cases, or verified fixes).
2. Help review open issues and test proposed skills on real hardware (radios, VPS instances, or agent runtimes).
3. Open an issue with the title `[COLLABORATOR] Application: <Your Name / Callsign>` detailing your areas of expertise.

---

## 📜 Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for all, regardless of background, identity, or technical experience level. Please be respectful and constructive in all discussions, code reviews, and issue threads.
