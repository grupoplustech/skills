# 🖥️ Unified VPS Health Snapshot

Single-run, non-invasive terminal diagnostic protocol for assessing Linux server health across system resources, Docker containers, listening ports, active cron jobs, and SSL certificate expiration.

## 🎯 Use Cases
* Rapid triage when services appear degraded or unresponsive.
* Pre-deployment and post-update sanity checks on production VPS instances.
* Automated daily system audits delivered via agent summaries.
