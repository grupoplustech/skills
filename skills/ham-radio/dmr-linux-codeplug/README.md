# 📻 Native Linux DMR Radio Programming & Codeplug Engineering

Comprehensive guide, scripts, and edge-case catalog for programming Digital Mobile Radio (DMR) handsets (Baofeng DM-32UV, DM-1701, Radioddity, OpenGD77, TyT MD-380, AnyTone) on Linux using **qdMR** and **QLog**.

## 🎯 Use Cases
* Managing DMR Codeplugs (Channels, Zones, RX Group Lists, Talkgroups) natively in Linux.
* Understanding Codeplug Memory vs. User Contact Database limits.
* Fixing Linux GUI crashes in qdMR (Qt6 `libQt6Multimedia` segmentation faults vs APT Qt5).
* Managing USB programming cable permissions (`udev` rules, `dialout` group).
* Integrating DMR contacts with logbook software (QLog) and BrandMeister architectures.

## 📦 Supported Hardware & Tools
* **Software:** `qdmr` (GUI and CLI), `qlog` (Amateur Radio Logbook), `chirp` (Analog conversion).
* **Radios Tested:** Baofeng DM-32UV / DM-1701, Radioddity GD-77 (OpenGD77), TyT MD-UV380/390, AnyTone AT-D878UV.
* **OS:** Ubuntu 22.04/24.04, Linux Mint 21/22, Debian 12.
