# 📡 HF Digital Modes (FT8, FT4, JS8Call & CAT Control) on Linux

Configuration, calibration, and troubleshooting procedures for operating HF digital modes on Linux (Debian, Ubuntu, Mint) using WSJT-X, JTDX, and CI-V / Rigctl transceiver control.

## 🎯 Use Cases
* Interfacing Icom (CI-V) and Yaesu/Kenwood transceivers via serial CAT cables.
* Configuring audio pipelines (ALSA, PulseAudio, PipeWire) for soundcard digimodes.
* Fixing ALC overdrive, RF feedback in USB audio, and stuck PTT relays.
* Automating frequency hopping and WSJT-X configuration.
