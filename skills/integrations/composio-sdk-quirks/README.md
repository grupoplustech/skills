# 🧩 Composio SDK & MCP Router Quirks & Troubleshooting

Battle-tested troubleshooting playbook for diagnosing and resolving silent failures, authentication desyncs, and project mismatches in Composio SDK (v1.0+) and Model Context Protocol (MCP) integrations.

## 🎯 Use Cases
* Fixing `Connected Accounts: 0` despite accounts showing active in the dashboard.
* Resolving `Project Mismatch` errors when multiple CLI environments exist.
* Differentiating between 401 Unauthorized vs 502 Bad Gateway across Composio tool invocations.
