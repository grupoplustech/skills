# 📸 Headless Playwright Screenshot Capture for Protected Next.js Apps

Technique and script templates for capturing high-fidelity screenshots of authentication-protected Next.js applications (SSR, Server Actions, middleware redirects) for visual QA and multi-modal AI analysis.

## 🎯 Use Cases
* Visual regression testing behind login walls.
* Allowing vision-capable agents (Claude, GPT-4o, Gemini) to inspect authenticated dashboards.
* Bypassing Next.js middleware redirects via injected session cookies or preview tokens.

## 🛠️ Multi-Runtime Support
* Hermes Agent: `SKILL.md`
* Claude Code / Projects: `CLAUDE.md`
* Cursor: `CURSOR.mdc`
* Gemini AI Studio: `GEMINI.md`
* OpenAI GPTs: `GPT.md`
