# ♿ Web Accessibility (a11y) & WCAG 2.2 Audit for React & Next.js

Automated auditing protocol and linting patterns for evaluating WCAG 2.1 / 2.2 AA compliance across Next.js and React component trees (contrast ratios, focus traps, semantic landmarks, and ARIA roles).

## 🎯 Use Cases
* Pre-commit verification of accessibility issues in JSX/TSX files.
* Calculating color contrast ratios for light/dark themes according to WCAG AA (4.5:1 text, 3:1 UI).
* Detecting missing `alt` attributes, unlabelled interactive buttons, and invalid `aria-*` tags.
* Ensuring full keyboard navigation (focus rings, tab indexing, modal focus traps).
